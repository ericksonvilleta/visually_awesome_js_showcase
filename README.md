# Nexus Visuals 🌌
### Interactive JavaScript Creative Suite

**Nexus Visuals** is an immersive, high-performance web application showcasing three distinct generative JavaScript visual engines, built with HTML5 Canvas, modern CSS 3D transforms, and Tailwind CSS.

---

## ✨ Features & Visual Modules

### 1. ⚛️ Quantum Constellation (Module 01)
* **What it is:** A physics-based particle simulation engine.
* **Interactivity:** Move your cursor across the canvas to gently attract nodes and trigger dynamic neural triangulation links.
* **Customization:** Adjust particle density, maximum connection distance, speed multipliers, and switch between multiple color themes (*Cyber Blue*, *Neon Purple*, *Matrix Green*).

### 2. 🪄 Harmonic Kaleidoscope (Module 02)
* **What it is:** A procedural mathematical art generator utilizing radial symmetry matrices and trigonometric wave harmonics.
* **Interactivity:** Click or drag across the canvas to morph sacred geometric patterns in real-time.
* **Customization:** Tweak symmetry segments (3 to 24), rotation speed, color frequency, and clear/reset the canvas on demand.

### 3. 🧊 Cybernetic 3D Card (Module 03)
* **What it is:** An immersive 3D card tilt effect featuring realistic perspective depth and lighting.
* **Interactivity:** Hover and move your mouse across the card to tilt it along the $X$ and $Y$ axes.
* **Customization:** Watch dynamic holographic glare specular highlights track your cursor, adjust tilt intensity, and regenerate secure passkey identification codes.

## 🚀 Getting Started

No complex build steps or package installations are required! Because this project is built with vanilla web technologies, you can run it instantly:

1. Clone or download this repository.
2. Open the `index.html` file in any modern web browser (Chrome, Firefox, Safari, Edge).

---

## 🛠️ Built With

* **HTML5 Canvas & WebGL / 3D Transforms** for high-performance rendering.
* **Tailwind CSS** for rapid styling and responsive layout design.
* **FontAwesome & Google Fonts** (Inter & JetBrains Mono) for modern typography and iconography.
* **Vanilla JavaScript (ES6+)** with zero heavy external frameworks.
